Render 배포 방법

이 프로젝트는 Render에서 일반 Node 서버와 SQLite로 실행할 수 있습니다.
방명록·커뮤니티는 이름을 입력해 비회원으로 작성합니다. Q&A와 회원정보는 기존 구글 로그인을 사용합니다.

1. 수정한 파일을 GitHub 저장소에 커밋·푸시합니다.
2. Render의 Web Service에서 해당 저장소와 main 브랜치를 선택합니다.
3. 다음 값을 입력합니다.
   Language: Node
   Root Directory: 빈칸
   Build Command: npm ci --include=dev && npm run build:render
   Start Command: npm start
   Health Check Path: /api/health
   환경변수 NODE_VERSION: 22.16.0
   PORT: 직접 추가하지 않습니다. Render의 PORT를 자동으로 사용합니다.
4. Deploy Web Service 또는 Manual Deploy > Deploy latest commit을 실행합니다.
5. 배포 주소에서 방명록과 커뮤니티의 비회원 글쓰기를 확인합니다.

게시글을 계속 보관할 때
Render의 유료 Web Service에서 영구 디스크를 추가합니다.
Mount Path: /var/data
환경변수 SQLITE_PATH: /var/data/argo.sqlite
render.yaml은 이 구성을 담고 있으며 Starter와 디스크는 유료입니다.
Blueprint를 이용하면 파일의 설정으로 서비스를 생성할 수 있습니다. 실제 비용은 Render 화면에서 확인하세요.

무료로 접속만 테스트할 때
Free 인스턴스에서 위 빌드·시작 명령을 사용할 수 있습니다.
SQLITE_PATH는 생략하면 .data/argo.sqlite를 사용합니다.
Free에는 영구 디스크가 없으므로 재시작·슬립·재배포 시 게시글이 사라질 수 있습니다.
로컬 DB와 Render DB는 별개이며, 로컬 글을 자동으로 전송하지 않습니다.

선택 설정
구글 로그인: GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, AUTH_SECRET을 설정합니다.
APP_ORIGIN은 생략하면 Render의 공식 서비스 주소를 사용합니다.
사용자 도메인을 쓰면 APP_ORIGIN에 실제 HTTPS 주소를 입력하고 Google 리디렉션 URI도 수정하세요.
네이버 지도: NAVER_MAP_CLIENT_ID를 설정하고 Maps 콘솔에 배포 도메인을 등록합니다.

산업재해 통계
메인 최상단의 연도 선택으로 2023~2025년 통계를 비교합니다.
고용노동부 원문을 대조한 고정 연간 데이터이며 실시간 집계가 아닙니다.
산업재해 건수와 재해자 수를 구분합니다. 안전/보건은 사고/질병 재해자(명) 기준입니다.
화학물질 중독과 근골격계질환은 화면에 표시한 세부 항목의 인원 합계입니다.
2025년 산업재해 발생 건수는 확인한 현황표에 없어 미수록으로 표시합니다.
화면의 '집계 기준·출처'에서 원문을 확인할 수 있습니다.

로컬 개발
npm run dev -- --hostname 0.0.0.0
기존 Cloudflare 개발용 DB와 실행 방식을 유지합니다.
Render용 빌드 검증: npm run build:render
빌드 후 실행: npm start
Cloudflare용 빌드: npm run build / 실행: npm run start:cloudflare
