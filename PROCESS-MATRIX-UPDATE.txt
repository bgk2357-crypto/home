분류 연결창에 대분류·중분류·소분류·기타 추가 분류를 처음부터 표시.
상위 분류 선택 시 해당 자식 분류 활성화. 추가 분류 아래 단계도 계속 선택 가능.
원하는 단계까지 선택한 후 분류 연결 저장. 흐름도에 없는 분류는 먼저 흐름도에서 추가·저장.

[MSDS 도형 선택 · 상단 업로드 · 분류 연결 개선본]

1. 도형 선택과 아래 편집란 연동
- 흐름도 도형의 이름/본문을 클릭하면 테두리가 강조되고 '선택됨' 표시.
- 아래 '선택한 분류' 목록, 이름, 작업내용이 선택 도형과 연동됨.
- 아래 '선택한 분류' 목록으로 선택을 바꿔도 도형 강조와 편집란이 함께 변경.
- 작업내용 수정 → '수정 내용 적용' → '공정흐름도 저장'.
- 새 분류 추가는 '선택한 분류'에서 '새 분류 추가' 선택 또는 각 도형의 '+ 하위' 사용.
- 분류 총 200개, 이름 80자, 분류별 작업내용 2,000자.

2. MSDS 업로드 화면
- 등록할 분류 선택 영역을 상단 가로 전체 폭으로 배치.
- 분류 이름 검색 및 단계별 선택 목록, 오른쪽 끝 '확인 · 분석 시작' 버튼.
- 그 아래 드래그앤드롭 / 파일 추가 / 폴더 추가, 이어서 분석 대기 목록.
- 파일을 선택하는 것만으로 분석되지 않음. 확인 버튼을 눌러야 분석·저장.
- 등록할 분류를 선택해야 분석 가능. 분석 전 파일은 대기 목록에서 제거 가능.

3. 자료 표와 대시보드의 분류 연동
- 규제 검토표, 특별관리물질 검토표, 대시보드/자산목록의 부서·공정·작업 칸에
  '분류 연결' 또는 '분류 변경' 버튼 추가.
- 기존 미연결 자료도 버튼을 눌러 흐름도의 분류 선택 → '분류 연결 저장'.
- 같은 MSDS의 모든 성분 행과 대시보드가 함께 변경됨.
- 분류 이름 표시를 흐름도 데이터에서 가져옴. 이름 변경도 연동.
- 상위 분류만 연결한 경우 연결된 단계까지만 표시. 빈 하위 단계의 미지정 문구 없음.
- 분류 변경 시 검토/현장게시 상태를 해제하므로 검토 후 필요한 자료를 다시 게시.
- 대시보드 및 자산목록에서 '부서·공정·작업 / CAS' 제목을 '부서·공정·작업'으로 변경,
  그 칸 아래 CAS 번호 목록도 제거. 성분별 규제 검토에 쓰이는 CAS 원본 데이터는 보존.

4. NAS 배포
파일: C:\home\outputs\HOME_MSDS_전체분류연결_NAS배포본.zip
가) 운영 NAS의 web/argo 및 argo-homepage-data 백업.
   데이터 백업 중에는 홈페이지 서비스를 잠시 중지하고 완료 후 다시 시작.
나) PC에서 ZIP 압축 해제.
다) public 폴더 안의 내용을 NAS web/argo/public 에 덮어쓰기.
라) server 폴더 안의 내용을 NAS web/argo/server 에 덮어쓰기.
마) 기존 web/argo/config.php 와 argo-homepage-data 는 교체하지 않음.
   config.example.php 는 예시이므로 실제 설정 파일 대신 사용하지 않음.
바) 서비스 재시작 후 브라우저 Ctrl+F5 새로고침.
   public/public 또는 server/server처럼 폴더를 이중으로 만들지 않도록 주의.

HOME 원본과 배포 ZIP을 준비하고 별도의 로컬 검토 데이터로 검증한 상태.
NAS 운영 서버에는 위 절차로 별도 반영 필요.
운영 회원 데이터·실제 config.php·검토용 데이터는 ZIP에 포함되지 않음.
