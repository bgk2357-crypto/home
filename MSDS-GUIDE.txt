사용 순서
1. PDF·HWP 5·HWPX·DOCX·UTF-8 TXT 파일을 선택합니다. 파일당 10MB, PDF 80페이지, 한 번에 10개까지입니다.
2. 제품·공급자·주소·일반/긴급전화·권고용도·사용제한·CAS·분류와 조치사항을 확인합니다.
   표 안의 분리된 라벨/값과 PDF의 줄 배치를 반영해 추출합니다. 원문에서 확인되지 않은 값은 임의로 채우지 않습니다.
3. 원문 2항의 코드/그림문자 이름 또는 표준 GHS 그림과 높은 신뢰도로 일치한 이미지를 자동 체크합니다.
   편집자가 추가 체크/해제할 수 있습니다. 불확실한 이미지와 스캔 문자에는 자동 판독 한계가 있으므로 원문과 대조합니다.
4. 공급자명·주소·전화번호와 별도로 사용 회사명·부서·공정을 수정할 수 있습니다.
5. 제품명·CAS·공급자 검색으로 목록을 좁히고 '검색 목록 엑셀 저장'을 선택합니다.
   엑셀은 물질목록, 취급·응급조치, 전체항목, MSDS16항, GHS그림문자, 추출원문의 여섯 시트를 포함합니다.
   GHS 코드는 명칭과 실제 그림으로 저장합니다. 긴 내용은 조각 번호 순서로 나누어 보존합니다.
6. 한글 2010에서는 '한글 2010 호환(RTF) 저장'을 선택하고 한글의 파일 > 불러오기로 엽니다.
   한글에서 연 뒤 다른 이름으로 저장 > HWP를 선택할 수 있습니다. HWP 바이너리를 직접 생성하지는 않습니다.
   '한글 표준문서(HWPX) 저장'은 2010 SE+ 이상용입니다. 일반 한글 2010의 HWPX 미지원은 파일 이름 변경으로 해결되지 않습니다.
   두 형식은 기본정보·선택한 그림문자·1~16항·전체 추출 원문을 포함합니다.
   한글 2010 프로그램에서 실제 열기·인쇄 검증은 사용 중인 설치본에서 확인해야 합니다.
7. 용기 경고표지: 용량 구간과 mm 치수, 글자 크기를 선택하고 원문 검토 완료를 체크합니다.
8. 인쇄 미리보기에서 필수 항목·크기·그림문자·문구를 확인합니다.
   실제 크기 100%, 컬러, 머리글·바닥글 해제 설정으로 인쇄하거나 PDF로 저장합니다.
9. 한 장 유해성 안내는 회사명·공정명과 응급조치·보호구 등을 A4에 배치합니다.
   내용이 넘치면 인쇄가 차단됩니다. 상세 MSDS를 참고해 문구를 검토·편집한 뒤 다시 출력합니다.

표지 기준
안전보건공단의 경고표지 규격 페이지와 고용노동부 고시 제2026-26호의 별표 3을 참고합니다.
5~50L 미만 90cm2, 50~200L 미만 180cm2, 200~500L 미만 300cm2, 500L 이상 450cm2.
5L 미만은 상하 제외 용기 표면적의 5%를 확인합니다.
그림문자는 표지 면적 1/40 이상·최소 0.5cm2를 확보하도록 배치합니다.
신호어·제품명·그림문자·H/P 문구·공급자 정보는 원문과 대조해 확인합니다.
작은 용기의 표시 생략 예외나 그림문자 우선순위를 임의로 자동 적용하지 않습니다.
https://msds.kosha.or.kr/MSDSInfo/msds/web/kosha/msds02/Msds02WarningList.jsp
https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000278320&chrClsCd=010202

처리 범위와 보관
파일은 브라우저 내부에서 텍스트를 추출하며 서버로 업로드하지 않습니다.
이 브라우저의 IndexedDB에 분석·수정 자료를 저장하므로 기기·브라우저·사이트 주소가 바뀌면 공유되지 않습니다.
중요 자료는 엑셀·한글 파일로 내려받아 보관하세요. 브라우저 데이터 삭제 시 저장 자료가 사라집니다.
스캔 PDF의 문자 OCR과 혼합물 위험성 재분류는 지원하지 않습니다.
HWPX/DOCX의 내장 래스터 그림과 PDF 앞 5쪽 및 확인된 2항 페이지에서 표준 GHS 그림을 보수적으로 대조합니다.
변형된 그림·낮은 해상도·벡터/메타파일·나머지 페이지의 그림은 자동 선택되지 않을 수 있습니다.
업데이트 전에 분석한 자료는 원본 파일을 다시 선택해야 개선된 추출 결과와 그림 인식이 적용됩니다.
잠금·배포용·DRM 한글 파일은 일반 HWPX 또는 PDF로 저장한 뒤 사용하세요.
공단 검색은 입력 검색어를 공단 공식 사이트로 전송해 새 창에서 검색합니다. API 키 없이 사용할 수 있습니다.

배포
기존 Render 명령을 그대로 사용합니다.
Build Command: npm ci --include=dev && npm run build:render
Start Command: npm start
PDF 분석 worker는 빌드 시 설치한 pdfjs-dist 버전에서 public/vendor로 복사합니다.
