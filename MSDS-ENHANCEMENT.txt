MSDS 현장 게시·법정 대상 검토·측정결과 기반 업데이트 (2026-10-26)

1. 현장 게시 및 삭제
- 사업장·현장 게시 설정 아래에 모든 등록 MSDS 목록을 추가.
- 자료별 게시/게시 해제, 정보 수정, 원본·자료 삭제 제공.
- 게시 해제는 원본 유지. 원본·자료 삭제는 원본과 등록 데이터 삭제.
- 게시·해제·게시 중 수정·자료 삭제 작업 이력은 원본과 별도로 계정별 기록.
- 원본을 삭제해도 이력은 남음. 이력 삭제는 별도 제공, 원본에 영향 없음.
- 이번 업데이트 이전에 삭제된 자료/이력은 복구하지 않음. 과거 기록은 백업 필요.
- 현장 뷰어에서 게시 해제 및 게시 목록·삭제·이력 관리로 이동 가능.
- 일반 MSDS 목록의 카테고리 필터가 현장 뷰어를 숨기지 않도록 분리.

2. 회사·부서·공정·게시위치
- 회사명, 기본 사용부서, 기본 작업공정, 기본 게시위치, 공지 저장.
- 자료별 사용 사업장·사용부서·작업공정·게시위치도 개별 수정 가능.
- 자료별 값이 없으면 현장 게시 목록/뷰어에서 기본값을 사용.
- 자료의 성분·관리요령·부서 등을 수정하면 검토 완료/게시를 해제하며,
  원문과 수정 내용을 다시 검토한 뒤 확인·게시 가능.

3. 성분별 법정 대상 검토
- 원문 3항에서 물질명·CAS·함유량·중량/용량 비율 초안 추출.
- 직접 성분 추가·수정·행 제거, 특별관리 적용 조건과 확인 메모 입력.
- 관리대상 유해물질, 특별관리물질, 작업환경측정 대상, 특수건강진단 대상을 구분.
- 현행 법령에 연결된 공식 별표 PDF와 CAS가 명시된 화학물질 목록 사용.
  * 안전보건기준 규칙 별표 12: 181개 명시 화학물질 항목
  * 산업안전보건법 시행규칙 별표 21: CAS 명시 181개 화학물질 항목
  * 산업안전보건법 시행규칙 별표 22: CAS 명시 162개 화학물질 항목
  * 확인일 2026-10-26. 각 PDF·출처 링크·SHA-256은 regulation-data.json에 기록.
- 공식 별표의 CAS 직접 일치 + 입력 함유량과 비율 기준을 대조한 참고 결과임.
- 화합물군·이성질체 전체 CAS 확대, 분진·소음·야간작업, 실제 노출/작업장
  적용 의무까지 자동 확정하는 기능은 아님.
- 함유량 미확인, 중량/용량 불일치, 기준을 걸치는 범위, pH·불용성 등 조건은
  '확인 필요'로 표시. 미일치를 곧바로 미대상이라고 표시하지 않음.
- 특별관리물질은 일반 1%만으로 처리하지 않고 별표의 0.1%·0.3% 및 조건 확인.
- 특별관리물질 검토 화면에 제품명·CAS·물질명·함유량·사용부서·공정과 근거 표기.
- 회원이 원문 검토 화면에서 수정·저장한 성분/사용부서를 해당 표에 즉시 반영.
- CSV 표 다운로드. 작업공정별 관리요령 추가·수정·저장·인쇄/PDF 및 HWPX 반영.
- 자동 추출은 초안이므로 원문과 최신 법령을 확인해야 함. 제공 목록은 날짜가
  명시된 스냅샷이며 자동으로 향후 법령 개정을 반영하지 않음.

4. 작업환경측정결과 업로드 기반
- CHARM 메뉴에서 PDF/HWP/HWPX/DOCX/XLSX/CSV/TXT 결과표 등록.
- XLSX/CSV는 제공 입력양식의 열 이름으로 측정일·부서·공정·위치·물질·CAS·
  결과값·단위·기준값·기준단위·측정구분·기준구분 추출, 원본과 함께 저장.
- 비정형 PDF 등은 원문을 보관하고 행 추가·수정으로 보정. 이미지 OCR은 미연결.
- 보고서당 최대 300행, 파일당 5MB. MSDS와 측정결과를 합해 계정당 100건 한도.
- 행별 검토·수정·저장, 보고서 원본 열기·삭제, CAS 일치 MSDS 표시.
- 사용자가 입력한 기준과 결과의 단위/평가시간이 같을 때만 비율 비교.
- 불검출·부등호·단위 차이·TWA/STEL 차이·미확인은 계산하지 않고 확인 요청.
- 최신 법정 노출기준 자동 검색, 단위 자동 변환, CHARM 최종 위험점수 산출은
  이번 기반 기능에 포함하지 않음. 비교값은 '입력 기준 대비'로 표시.

저장/호환성
- 기존 data_dir/argo.sqlite 유지. msds_assets의 JSON 항목을 확장하므로 기존 자료 유지.
- 측정결과도 같은 소유자·버전·원본 파일 보호 구조로 저장하며 일반 MSDS와 분리 표시.
- server/migrations/0005_publication_events.sql이 게시 이력 테이블을 자동 추가.
- SQLite 3.10 호환 SQL 유지. 계정별 조회/다운로드/수정/삭제, CSRF, 버전 충돌 검사 유지.

NAS 적용
1. 홈페이지와 데이터 폴더 전체를 정상 백업.
2. 홈페이지 서비스를 잠시 중지.
3. C:\home\outputs\HOME_MSDS_게시분류측정_개선_NAS배포본.zip 압축 해제.
4. public와 server를 NAS web/argo의 동일 폴더에 함께 덮어쓰기.
5. 기존 config.php·data_dir·Google 설정·인증서·가상 호스트는 유지.
6. 서비스 시작, Ctrl+F5. 첫 DB 연결에서 0005 항목 자동 추가.
7. 게시 설정의 목록·이력, 성분별 검토, 측정결과 업로드/저장 확인.
이 파일 작성 시 HOME 원본·배포본 준비와 로컬 검증만 수행. NAS에 자동 업로드하지 않음.
