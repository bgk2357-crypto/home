회원전용 업무 대시보드 업데이트 — 2026-10-26

이번 적용 범위
1. 주요실적을 회사소개 > 연혁 다음으로 이동. 옛 /business/achievements 주소도 유지.
2. 상단 내 회원정보는 /members 유지. 회원 전용 서비스는 /services로 분리.
3. 서비스 목록 4개에서 각각 새 창(또는 브라우저의 새 탭)으로 대시보드 열기.
   - /workspace/system: 안전보건관리체계 구축
   - /workspace/risk: 위험성평가
   - /workspace/ergonomics: 근골격계부담작업 유해요인조사
   - /workspace/msds: 물질안전보건자료
4. 업무 대시보드는 정회원·마스터만 이용. 화면과 저장·다운로드 API에서 모두 검사.
5. 앞의 3개 업무는 좌측 업무 메뉴와 시작 화면 단계. 상세 업무 기능은 후속 구현.
6. 자료실 MSDS는 일반회원 이상 맛보기: 최대 3건, 기존 브라우저 저장 방식 유지.

MSDS 업무 대시보드
- 등록 현황, 검토 필요·완료, 게시 현황
- 파일 선택·폴더 선택·끌어놓기, 등록 그룹 이름·부서/공정 지정
- PDF/HWP/HWPX/DOCX/TXT 기본 텍스트 추출, XLSX/UTF-8 CSV 표 텍스트 추출
  구형 XLS는 XLSX로 변환 후 사용. 암호화·스캔 문서는 사전 처리 필요.
- 텍스트 PDF는 최대 80쪽, 파일당 5MB, 한번에 10개, MSDS·측정결과를 합해 계정당 최대 100건
- 한 파일은 한 자료로 등록. 여러 제품 문서의 자동 분할은 현재 미구현.
- 원본 보관·다운로드, 제품/CAS/공급자/번호 검색, 분류 필터, 개별 삭제
- 원문 PDF 또는 추출 텍스트와 제품·성분·CAS·H코드·GHS·유해성 정보 대조·수정
- 검토 완료와 현장 게시 선택. 정보 변경 시 검토 완료·게시 해제
- 검토한 자료의 경고표지 미리보기·인쇄/PDF 저장, 유해성 안내
- 관리요령, 담당자가 입력한 규제/특별관리물질 검토 메모를 인쇄/PDF로 출력
- 목록 Excel, 개별 검토자료 HWPX 내려받기
- 부서/공정 카테고리, 사업장 이름·공지, 같은 회원 계정의 현장 뷰어

추가 설명서·외부 연결이 필요한 범위
- 생성형 AI 추출/보정, 이미지 OCR 서비스는 연결하지 않음. 기본 텍스트 추출로 명시.
- 별표 12·21·22의 날짜가 명시된 CAS·함유량 대조표를 제공. 화합물군 전체 확장과 법적 적용 의무 자동 확정은 미구현.
  규제·특별관리물질 출력은 목록 대조 참고와 담당자 검토 메모이며 자동 법적 판정 결과가 아님.
- CHARM 메뉴는 작업환경측정결과 원본·정형 표 업로드, 행별 수정·저장, CAS 연결과 입력 기준 대비 비율 검토를 제공.
  평가 기준·계산식 상세 설명서를 받기 전 점수나 위험등급을 산출하지 않음.
- 별도 현장 계정 배포, 계정별 단말 제어, 열람 이력, 사용자 정의 속성,
  자동 문서 분할·배치 산출물·엑셀 병합 등은 후속 상세 요구사항 대상.
- 참고 제품의 로고·회사 이력·과금/크레딧을 가져오지 않고 Argo 브랜드로 구성.

저장 위치
NAS config.php의 data_dir/argo.sqlite에 새 테이블이 자동 추가됨.
msds_assets: 원문 추출·수정 데이터, 계정 소유권, 검토/게시, 분류, 버전
msds_original_chunks: 실제 원본 파일을 나눠 저장
msds_workspace_settings: 계정별 회사명·부서·공정·게시위치·공지·분류
msds_publication_events: 원본과 별도로 보관하는 게시·자료 작업 이력
측정결과는 msds_assets의 kind=measurement와 측정 행 JSON으로 구분 저장.
다른 회원의 자료는 계정별로 분리. 같은 회원 계정으로 로그인한 기기는 공유.
맛보기 브라우저 저장 데이터와 정회원 서버 저장 데이터는 자동 이전·동기화하지 않음.
사이트 운영자는 서버 저장 데이터에 접근 가능.

NAS 반영 순서
1. 정상 홈페이지와 data_dir 전체를 백업.
2. 홈페이지 서비스를 잠시 중지.
3. C:\home\outputs\synology-webstation.zip 압축을 푼 public와 server를 함께 갱신.
4. 기존 config.php와 data_dir는 보존. 기존 Google 키·인증서·가상 호스트 설정 유지.
5. server/workspace.php와 server/migrations/0004_msds_workspace.sql 포함 확인.
6. 서비스를 시작하고 브라우저 Ctrl+F5.
7. 정회원·마스터로 회원 전용 서비스 > MSDS를 열고 등록·수정·새로고침·원본 열기 확인.
8. 다른 정회원은 본인 자료만 보이고 일반회원은 업무 API가 차단되는지 확인.
9. 자료실 맛보기와 내 회원정보는 별도 메뉴인지 확인.
