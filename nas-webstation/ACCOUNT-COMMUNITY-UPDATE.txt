3. 메일 발송 설정 (필수 운영 설정)
수신 이메일은 가입 이메일로 고정됩니다. 이와 별개로 서버가 메일을 보내기 위한 발신 설정이 필요합니다.
현재 프로젝트에 실제 발신 주소/서비스 자격증명이 없으므로 외부 메일의 실제 수신 완료까지 검증하지 않았습니다.
메일 설정 전에는 비밀번호 찾기 화면에 ‘메일 발송 준비 중’ 안내가 표시됩니다. 이메일 로그인 자체는 계속 가능합니다.

NAS의 비공개 config.php에 다음 중 한 방법을 직접 설정:
 A) NAS에서 PHP mail()의 SMTP/MTA를 이미 운영 중일 때:
    'mail_transport' => 'mail',
    'mail_from' => '실제 발송 권한이 있는 이메일 주소',
    PHP mail()가 성공해도 받은편지함 전달을 보장하지 않으므로 실제 수신함·스팸함 확인 필요.
 B) Resend 형식의 HTTPS JSON 메일 API를 사용할 때:
    'mail_transport' => 'api',
    'mail_from' => '서비스에서 인증한 발신 이메일',
    'mail_api_url' => 'https://api.resend.com/emails',
    'mail_api_key' => '실제 API 키',
    PHP cURL 확장과 외부 HTTPS 통신이 필요. API 키는 비공개 config.php에만 입력.
 app_origin은 사용자가 실제 접속하는 HTTPS 홈페이지 주소로 지정. 입력받은 Host로 재설정 링크를 만들지 않음.
 운영 중 서비스의 발신 도메인 인증·요금·한도는 해당 서비스 설정을 확인.
 Node/Worker 운영 시 비공개 환경변수 MAIL_FROM, MAIL_API_URL, MAIL_API_KEY, APP_ORIGIN을 사용.
 발신 이메일 비밀번호/앱 비밀번호/API 키를 대화·공개 폴더·배포 ZIP에 넣지 말 것.
