운영 방식
- 열람·다운로드는 공개, 등록은 기존 Google 로그인 및 홈페이지 회원가입을 완료한 회원만 가능합니다.
- 글: 제목 100자, 내용 20,000자. 첨부 없이 안내 글만 올릴 수도 있습니다.
- 첨부: 최대 3개, 각 5 MB. 전체 요청은 16 MB 이하입니다.
- 지원: PDF/HWP/HWPX/DOCX/XLSX/PPTX/PNG/JPG/JPEG/UTF-8 TXT/CSV/ZIP.
- 형식·용량·파일 시작 바이트를 서버에서 확인합니다. 업로드한 자료는 첨부 다운로드로 제공합니다.
- 신규 게시글과 첨부파일은 기존 데이터베이스 안에 함께 저장됩니다. 브라우저 저장소에만 남는 기능이 아닙니다.
- DB 밖의 임의 경로에 파일을 만들거나 사용자 파일명을 서버 실행 경로로 사용하지 않습니다.
- 원래 회원정보·방명록·커뮤니티·Q&A 테이블을 수정·삭제하지 않는 추가 마이그레이션입니다.
- 다음 DB 연결 때 drizzle/0002_safety_resources.sql이 자동 적용됩니다.
- 가이드북(검토용), 7가지 체크리스트, 7가지 핵심요소의 기본 자료 3건이 최초 등록됩니다.
- 파일과 글은 공개되므로 민감정보 없이 공유 권한이 있는 자료만 등록하도록 안내합니다.
- 삭제·수정·관리자 승인 기능은 이번 범위에 포함하지 않았습니다. 삭제 요청은 기존 운영자 문의 방식을 이용합니다.
- 업로드 자료가 늘면 SQLite/D1 저장공간이 증가합니다. 기존 DB 백업에 첨부파일도 포함됩니다.

NAS Web Station
- 배포 파일: outputs/synology-webstation.zip
- 기존 config.php와 data_dir의 DB는 유지하세요. 새 ZIP에는 비밀 키와 실제 회원/게시글 데이터가 없습니다.
- PHP 소스만 일부 복사하지 말고 새 public 화면·server 코드·server/migrations를 함께 업데이트하세요.
- public/.user.ini에 upload_max_filesize=5M, post_max_size=16M, max_file_uploads=10을 포함했습니다.
- NAS PHP 실행 방식에 따라 .user.ini가 적용되지 않을 수 있으므로 Web Station PHP 설정에서도 이 값을 확인하세요.
- 기존 PHP 설정이 제한하는 경우 더 작은 첨부 한도가 적용됩니다.
- 실제 NAS 업로드·서비스 재시작·도메인 배포는 이 로컬 소스 수정과 별개입니다.

내용 검수
- 첨부된 .crdownload 2개는 실제 PNG로 열리는 것을 확인해 정상 .png 이름으로 제공했습니다.
- 원본: 고용노동부·안전보건공단 2022-중대산재예방실-99 안내 이미지.
- 점검 질문은 원본의 취지와 7요소·25항목에 맞춰 재구성했습니다.
- 7대 핵심요소는 자율점검 구성 틀이며 현행 법정 의무 전체를 대신하는 기준이 아닙니다.
- 기존 25쪽 실무 가이드북은 사용자 검수가 진행 중인 자료로 표시했습니다. 내용을 확정한 최종본으로 오인하지 않도록 검토용이라고 안내합니다.
