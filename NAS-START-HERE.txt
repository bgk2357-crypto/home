NAS용 홈페이지 작업 위치

현재 작업은 모두 C:\home 안에 있습니다.

1. 기존 React/TypeScript 홈페이지
   C:\home\app
   C:\home\components
   C:\home\lib
   원래 개발·Node 서버 배포 구성을 유지합니다.

2. Docker 없이 실행하는 Web Station + PHP 버전 소스
   C:\home\nas-webstation\frontend  : 기존 React 화면을 연결하는 코드
   C:\home\nas-webstation\server    : PHP 로그인·게시판·Q&A·뉴스 서버
   C:\home\nas-webstation\public    : 공개 진입 파일 index.php
   C:\home\nas-webstation\INSTALL.txt : NAS 설치 안내
   이 소스의 public 폴더만 복사하면 완성된 화면이 나오지 않습니다.
   아래 빌드 결과 또는 ZIP을 사용하세요.

3. NAS에 실제 올릴 빌드 결과
   C:\home\outputs\synology-webstation.zip
   C:\home\outputs\synology-webstation\public\index.php
   ZIP을 NAS의 /volume1/web/argo에 풀고 문서 루트를 /volume1/web/argo/public로 지정합니다.
   나머지 설정은 ZIP 안의 INSTALL.txt를 따릅니다.
   비밀 키와 게시판 DB는 이 ZIP에 들어 있지 않습니다.

4. 소스를 수정한 뒤 다시 빌드
   Node.js가 설치된 PC의 C:\home에서:
   npm run build:webstation
   빌드 스크립트: C:\home\scripts\build-webstation.mjs
   outputs 폴더는 Git에서 제외됩니다. 집 PC로 Git 복제한 경우 빌드를 다시 실행하세요.

확인된 NAS: DS216+II / DSM 6.2.4 / 192.168.1.115
도메인: ssk2357.synology.me
현재 PHP: 7.4.30-0009
코드 호환성: PC의 PHP 7.4.30에서 110개 서버 검사를 통과했습니다.
별도 하위 버전 코드 변경 없이 기존 배포본으로 내부 설치 검증을 진행할 수 있습니다.
단, NAS PHP 패키지 자체의 보안 취약점은 홈페이지 코드 변경으로 해결되지 않습니다.
외부 공개 전 Synology-SA-26:14의 보안 수정 버전으로 업데이트 가능한지 확인합니다.
PHP 7.4 기준 공식 수정 버전은 7.4.33-0131 이상입니다.
https://www.synology.com/en-us/security/advisory/Synology_SA_26_14
